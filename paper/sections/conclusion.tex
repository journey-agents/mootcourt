On one publisher's archive, a base rate with a heavy-tailed density, fitted to concluded experiments, predicts how the next result will be distributed nearly as well as a prior fitted to the same experiments. The prior's pooled lead is small. Its interval lies above zero with the seven scored quarters held fixed, and with the quarters as the units it contains zero, so the lead is not shown; seven values are few, and that interval treats them as exchangeable. Without the quarter of July 2014 the pooled interval contains zero as well. Both forecasters beat a reference that uses no past effect and assumes no test has one. That reference is a floor, and nearly all of the gain over it is already in the base rate. More history improved the forecast: at each of the seven scored origins, a prior fitted on a quarter of the past tests scored worse than one fitted on all of them. The prior's skill on which test will be significant is small and fragile. Its interval lies above zero with tests resampled and, narrowly, with the seven quarters as the units, but not once one cell and quarter is left out, not on the event at planned precision, and not after recalibration (Table~\ref{tab:fmt-skill-by-origin}). It is a better level per cell and quarter and not a ranking of tests, and a large share of it comes from the one cell and quarter in which the unsmoothed base rate was zero. In the main run, forecasts as issued fail a calibration test against the realized event. Since the prior gives one probability per cell and quarter, the error is one of level, and the level misses in both directions across quarters. Weighting by precedents does not beat the prior, and a positive control on five simulated ledgers shows that the precedent rung, replayed this way, recovers too little of a planted signal for that result to rule out a signal of the planted size. A simple text classifier on the headlines ranks tests better than a random order matched on arm count. Against a rule that only counts arms its interval spans zero, on a target that itself grows with the number of arms, and it fails the planted control, which therefore neither validates nor explains that ranking. These models are simple stand-ins, so the result sets no bound on what published text models would achieve under this protocol. Abstention is not shown to select better or worse forecasts, and it stays as a label of evidence. In the sizing simulation, at its primary audience size, sizing a test from the forecast shows no measurable advantage over sizing it from a base rate.

The claims come with limits. Each number is exploratory: a single split of a single publisher's archive, looked at again and again, with the method changed from run to run after results had been seen. The main specification is itself one of those changes. Under the first specification, which read each test's own traffic and scored the base rate with a normal density, the prior's lead looked far larger, and Section~\ref{sec:ladder-results} reports both. With exposure fixed, the comparison of the prior with the base rate does not test what the prior adds when a test's precision is known (Section~\ref{sec:ladder-results}). The system has never been run in production, and this paper shows nothing for product experiments. Still unopened, the confirmatory split stands as the next test. A team reading this paper can take away the protocol: apply the same backtest to its own ledger and read that report's intervals. The gates tell how many tests a stated skill requires, and the abstentions state the condition each forecast met. Here, neither one was shown to pick out the good forecasts. On the single archive big enough to read, the backtest pointed to where forecasts fail, and nobody has yet shown it certifying the forecasts that succeed.
