Every result outside this section comes from one split of the headline archive that we read many times. The archive's maintainers ask that an analysis of its second, confirmatory split be registered first. On 14 November 2026 we registered three primary readings, each with a rule that turns its numbers into a verdict\iftmlr{} (a dated record, withheld for review)\else{} (commit afad501, pushed to the public repository that day)\fi. The file was fetched on 15 November 2026 and analysed once, and the package's code did not change in between. The registration is our own dated record: no outside registry holds it, and no journal reviewed it.

One registered secondary reading was not run: the primary readings with the date rule switched off. No script that existed at the fetch can build that ledger for this split, and we changed no script afterwards. The README of the run folder \texttt{paper/data/run10-confirmatory} records this and smaller departures. One is that the script running the registered stages in order was committed less than a minute after the download finished, before the file was read.

The paper therefore claims the following as tested by a registered analysis, on further tests of the same seven quarters: the prior's lead over a heavy-tailed base rate is not shown with the quarters as the units, its skill against a smoothed base rate is not shown, and the text classifier is not shown to rank better than counting arms. Every other result, the secondary readings above included, remains exploratory.
