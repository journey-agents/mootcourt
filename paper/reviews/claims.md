# Claims register

Every claim sentence of the paper (the abstract, the introduction's contributions, the six hypotheses as planned and as read back in Section 9, every number-bearing sentence of Section 6, and the closing section), each with the report file and key that holds its evidence under `paper/data/run8-randomization-window` (run 6 repeated on commit 82ba862 under the mid-rank tie rule of the calibration percentile, docs/method.md call 255). Written 4 November 2026 against the run 6 build of `paper/main.tex` and switched to run 7 the same evening (pass 9) with no printed value moved: the tie rule moved only per-cell percentile fields, and every percentile the register reads is a pooled cell; the audit of the convergence plan's Task 3 step 6 changes the status column.

Conventions. The sentence column quotes the clause that carries the claim, with LaTeX removed. The report path is relative to the repository root. The key path uses `tables.<name>[<col>=<value>,...].<field>` for a row of a table, plain dots for scalars, and `[" "]` around a dictionary key that itself contains a dot (the gates file). The printed value is exactly what the paper prints: "minus x" and "plus x" carry the sign, "N percent" and "N points" are the key's value times 100, a count keeps its thousands separator, and a verdict string or a boolean is quoted as the file holds it; a key path may start with `neg:` (the paper prints the difference the other way round: C4, C101, C108) or `pct:` (the paper prints percentage points of a fraction: C14, C102, C107). The interval kind is adjusted when the sentence rests on a Bonferroni-adjusted bound, plain when it quotes a 90 percent by-test interval, and none otherwise. A design or protocol claim has no report, key or value.
